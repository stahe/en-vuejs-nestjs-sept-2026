# A Client/Server Example - Vue.js / NestJS

This repository accompanies the course **“A Client/Server Example - Vue.js / NestJS”**, available online at:

**➡️ [https://stahe.github.io/en-vuejs-nestjs-sept-2026/](https://stahe.github.io/en-vuejs-nestjs-sept-2026/)**

## Overview

This course details the development of a complete client/server application, **RdvMedecins** (medical appointment scheduling), through:
- a **[NestJS]** server exposing a REST API (JWT authentication, MySQL database, TypeORM entities);
- a **[Vue.js] 3** client (Composition API, `<script setup>`, TypeScript) that consumes this API, with session management, French/English internationalization (`vue-i18n`), and an interface tailored to the logged-in user’s role (administrator/user).

This course revisits and builds upon the "business logic" features of an application developed in previous versions of the course (AngularJS 1.x, then Angular and React), to facilitate an educational comparison between these different client-side frameworks, with the NestJS server remaining consistent throughout.

Each chapter of the course provides line-by-line code commentary for significant code snippets in sections titled “Let’s Comment on This Code.”
